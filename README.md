# Mountain view: a Claude theme

A theme for Claude Code sessions in the Claude desktop app (and Code sessions opened in the mobile app). It paints the window as a sunny fjord seen from a mountain top: clear blue sky, grey granite peaks with snow, green slopes and deep blue water.

- **Colours from the view:** moss-green accent, sky-blue side panel, fjord-navy text. Light and dark mode.
- **Sun and rays in the top left** that follow your local time: soft in the morning, bright from late morning to evening, an orange-pink glow at dawn and sunset, and no rays at night.
- **Birds fly across the sky while Claude is working** on a task, and disappear when it's done.

## Install

At the prompt of a Claude Code terminal session:

```
/plugin install mountain-view --marketplace MdhhMnsr/Claude-theme-mountain-fjord
```

From a shell:

```
claude plugin install mountain-view --marketplace MdhhMnsr/Claude-theme-mountain-fjord
```

In the desktop app: click **+** next to the prompt box, then **Plugins**, **Add marketplace** with `MdhhMnsr/Claude-theme-mountain-fjord`, then **Add plugin**.

Start a new Code session to see the theme. The terminal and editors don't draw themes.
